# Akara SEO Keyword Map

Search ranking cannot be guaranteed. The goal is to build the strongest technical and content foundation around Akara's real product: WhatsApp-first peer-to-peer currency exchange coordination.

## What Is Now Covered

- Crawlable landing, trust, support, legal, corridor, and guide pages.
- Sitemap coverage for static pages, legal pages, 20 currency corridor pages, and SEO guide pages.
- Structured metadata, canonical URLs, Open Graph data, Twitter cards, JSON-LD, robots, and a web app manifest.
- Clear no-custody wording so Akara does not claim to be a bank, wallet, escrow provider, remittance company, bureau de change, or money transfer operator.
- Useful guide content for real search intent instead of keyword stuffing.

## Primary Positioning

Akara helps verified users list rates, discover offers, open Akara Trades, exchange payout details, upload receipts, track trade status, and raise disputes inside WhatsApp. Akara does not hold or move user funds.

## Weekly SEO Loop

1. Submit `https://tryakara.com/sitemap.xml` in Google Search Console.
2. Review queries, impressions, CTR, and average position.
3. Pick one corridor or use-case page from real search demand.
4. Improve the page using actual questions people search for.
5. Add internal links from the homepage, trust page, support page, and relevant guides.
6. Add descriptive alt text to new product images and mockups.
7. Keep no-custody and regulatory wording consistent.
8. Submit changed pages for indexing after meaningful releases.

## On-Page Rules

- One clear H1 per page.
- Page title under 60 characters where possible.
- Meta description around 140 to 160 characters.
- First paragraph must say what Akara does in plain language.
- Use keywords naturally. Do not stuff repeated terms.
- Do not claim Akara is a bank, remittance provider, wallet, escrow, payment processor, or bureau de change.
- Use schema where the page has FAQ, service, organization, guide, or article content.
- Prefer fast WebP images with useful alt text.

## What ChatGPT Can Keep Producing

- New guide drafts by corridor.
- Use-case pages for students, freelancers, travellers, expats, and community groups.
- FAQ expansions based on Search Console queries.
- Short WhatsApp-safe summaries of legal and safety pages.
- Meta title and description variants for A/B testing in Search Console.

## Search Reality

Google's own guidance is clear: ranking first cannot be bought or guaranteed by technical changes alone. Akara can improve crawlability, usefulness, page quality, internal linking, performance, and content coverage. The ranking loop depends on publishing useful pages, earning trust, getting indexed, and iterating from real search data.
